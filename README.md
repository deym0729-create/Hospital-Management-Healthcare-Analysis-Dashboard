🏥 Hospital Management & Healthcare Analytics Dashboard

📌 Project Overview

The Hospital Management & Healthcare Analytics Dashboard is an interactive Power BI project designed to analyze hospital performance, patient information, financial data, and operational activities.

This dashboard converts hospital data into meaningful visual insights using KPIs, charts, graphs, and interactive filters. It helps users understand patient trends, treatment costs, hospital performance, and patient satisfaction.

🎯 Project Objectives

- Analyze overall hospital performance.
- Understand patient demographics and visit patterns.
- Monitor treatment costs and insurance-related expenses.
- Evaluate hospital operations and patient satisfaction.
- Support better healthcare management decisions through data visualization.

🛠️ Tools & Technologies Used

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Visualization
- Interactive Slicers and Filters

📊 Dashboard Pages

1. Hospital Overview

This page provides an overall view of hospital activities and patient visits.

Key Visualizations:

- Department-wise Patient Visits
- Visit Type Distribution
- Patient Visit Trends
- Department Performance Analysis
- KPI Cards
- Interactive Filters

Purpose: To understand hospital activity and identify departments with higher patient visits.

2. Patient Analysis

This page focuses on patient demographics and medical information.

Key Visualizations:

- Patient Count by Age Group
- Patients by Diagnosis Group
- Patient Distribution by Gender
- Patient Category Analysis
- KPI Cards

Purpose: To understand patient demographics, age distribution, and common diagnosis groups.

3. Financial Analysis

This page focuses on hospital expenses and treatment-related financial information.

Key Visualizations:

- Treatment Cost by Insurance Type
- Treatment Cost by Department
- Financial Distribution Analysis
- Cost Trend Analysis
- KPI Cards

Purpose: To analyze treatment expenses and understand the financial contribution of different insurance types and departments.

4. Hospital Operations & Performance

This page evaluates hospital operational performance and patient satisfaction.

Key Visualizations:

- Patient Satisfaction vs Target
- Department vs Visit Type Satisfaction Heatmap
- Department Visit Ranking by Year
- Operational Performance Analysis
- KPI Cards

Purpose: To monitor hospital performance, compare patient satisfaction, and identify areas that require improvement.

⭐ Key Features

- Four interactive dashboard pages.
- KPI cards for important performance indicators.
- Multiple charts and graphical visualizations.
- Interactive slicers and filters.
- Navigation buttons between dashboard pages.
- Easy-to-understand data presentation.
- Healthcare performance analysis.

💡 Business Insights & Recommendations

- Monitor departments with higher patient visits to improve resource allocation.
- Analyze patient age groups and diagnosis patterns to understand healthcare requirements.
- Compare treatment costs across insurance types to improve financial planning.
- Track patient satisfaction to identify areas needing improvement.
- Review department performance regularly to improve hospital operations.
